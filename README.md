# RL for Real

Course materials from the five-day reinforcement learning course held at NVIDIA’s Tel Aviv offices in October 2026, organized by Ido Greenberg and Gal Chechik.

- Course page: https://nvlabs.github.io/rl-for-real/
- Lecture recordings: https://www.youtube.com/playlist?list=PLdDikXPHgzA4
- PPO exercise: https://github.com/NVlabs/rl-for-real/tree/main/ex1-ppo
- LLM sentiment exercise: https://github.com/NVlabs/rl-for-real/tree/main/ex2-llm-sentiment
- LLM reasoning exercise: https://github.com/NVlabs/rl-for-real/tree/main/ex3-llm-reasoning

Recordings are in Hebrew; slides and exercises are in English.

## Contents

- `ex1-ppo/`, `ex2-llm-sentiment/`, `ex3-llm-reasoning/`: the code exercises. Each is self-contained, with its own README and setup; use a separate environment for each.
- `docs/`: the course website, including the lecture slides and the exploration notebook.
- `portrait-sources.json` and `logo-sources.json`: image provenance.
